# BloxMarket - متجر جاهز للتعديل في Visual Studio Code

## التشغيل
1. فك الضغط.
2. افتح المجلد في Visual Studio Code.
3. افتح `index.html` في المتصفح، أو استخدم إضافة Live Server.
4. لتعديل رقم واتساب واسم المتجر: افتح `config.js`.
5. لوحة الإدارة: `admin.html` والرقم الافتراضي `1234`.

## مهم
- هذا المشروع Front-End فقط.
- الطلبات يتم تجهيزها وفتحها في واتساب، ولا يوجد نظام دفع إلكتروني حقيقي مدمج.
- لوحة الإدارة الحالية تحفظ المنتجات والإعدادات في LocalStorage على نفس المتصفح والجهاز.
- لو تريد لوحة إدارة حقيقية تعمل لكل الزوار + قاعدة بيانات + تسجيل دخول آمن، ستحتاج Backend/قاعدة بيانات واستضافة تدعم ذلك.

## الملفات
- index.html: الصفحة الرئيسية
- style.css: التصميم
- script.js: السلة والطلبات والواجهة
- config.js: الإعدادات والمنتج الافتراضي
- admin.html: إدارة المنتجات محلياً
- assets/logo.jpg: الشعار الابتدائي
